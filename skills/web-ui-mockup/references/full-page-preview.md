# 전체 화면 목업 템플릿

페이지 전체나 페이지 전환을 보여주는 목업은 왼쪽 조작 패널과 오른쪽 전체 높이 미리보기로 만든다.
이 기준은 `web-ui-mockup`과 `prototype`의 전체 화면 UI 분기에 적용한다.
사용자가 산출물 형식이나 레이아웃을 별도로 지정하면 그 요청을 우선한다.

## 참조

- 사용자 지정 화면: [페이지 전환 미리보기](http://127.0.0.1:5198/transition-studies.html).
- 보관한 원본 HTML: [full-page-preview-reference.html](../assets/full-page-preview-reference.html).
- 원본 위치: `mockups/subpages/transition-studies.html`.

보관한 HTML은 조작 패널과 미리보기의 구조를 재사용하는 참조다.
원본 페이지 콘텐츠와 서버는 포함하지 않는다.
로컬 URL에 접속할 수 없어도 보관한 HTML을 읽고 같은 구조를 구현한다.

## 적용 조건

- 메인·상세·설정·대시보드처럼 페이지 전체의 화면 구성을 판단하는 목업.
- 페이지 이동, 라우트 전환, 화면 진입·이탈 모션을 직접 실행하는 목업.
- 페이지 전체를 보여주는 후보나 상태를 하나씩 전환하며 비교하는 시안.

사이드바·메뉴·카드만 보여주는 부분 UI 목업에는 이 틀을 강제하지 않는다.
승인한 디자인을 제품 코드에 적용하는 작업에는 목업용 조작 패널을 추가하지 않는다.

## 화면 구성

- 바깥 화면은 여백 없이 `100svh`를 채운다. 데스크톱은 `230px minmax(0, 1fr)`의 두 열을 사용한다.
- 왼쪽 패널은 흰색 바탕과 얇은 오른쪽 테두리를 사용한다. 파란색 제목과 세로 버튼으로 페이지·후보·상태를 선택한다.
- 선택한 버튼은 파란색 테두리와 연한 파란색 바탕으로 표시한다. 단일 페이지를 선택하는 버튼에는 `aria-current="page"`를 사용한다.
- 오른쪽은 남은 너비와 전체 높이를 채운다. 선택한 페이지 하나를 표시하고 페이지 내부 스크롤을 유지한다.
- 미리보기는 테두리 없는 `iframe`으로 제품의 스타일과 조작 패널을 분리한다. 기존 구조가 같은 분리를 제공하면 그 구조를 재사용한다.
- 시안 제목·설명·조작 버튼은 왼쪽에 둔다. 페이지를 축소한 카드 목록이나 큰 설명 헤더로 오른쪽 공간을 줄이지 않는다.

패널의 기준값은 원본 HTML의 `--blue: #006dd6`, `--line: #dce5ee`, `--pale: #eef5fd`다.
버튼의 최소 높이는 `42px`이고 패널 안쪽 여백은 `22px 16px`이다.
이 값은 목업 도구에 적용한다. 오른쪽 페이지는 작업 대상의 디자인을 유지한다.

## 조작과 연결

- 왼쪽에서 페이지·후보·상태를 고르면 오른쪽 내용과 선택 표시를 함께 갱신한다.
- 전환이나 모션을 검토하면 `다시 재생` 버튼을 둔다. 시작 상태로 복원한 다음 같은 동작을 다시 실행한다.
- `전체 미리보기` 링크는 조작 패널 없이 페이지를 연다. 선택한 후보와 필요한 URL 매개변수를 보존한다.
- 페이지 전환은 실제 미리보기의 링크나 라우터로 실행한다. 출발 화면, 이동 중 상태, 도착 화면을 확인할 수 있어야 한다.
- 폭이 `900px` 이하면 조작 패널을 접고 왼쪽 위 토글로 연다. 선택 후나 `Escape` 입력 후에는 패널을 닫는다.
- 토글은 `aria-controls`와 `aria-expanded`를 유지한다. 숨긴 패널은 `inert`로 초점에서 제외하고 닫은 뒤 토글로 초점을 돌린다.

원본의 경로·버튼 이름·`iframe` 주소·`.review-toolbar` 선택자는 원본 프로젝트 전용이다.
새 목업에서는 실제 미리보기 주소와 프로젝트의 이동 방식에 맞게 바꾼다.
부모 문서에서 `iframe`의 DOM을 읽는 원본 방식은 두 문서가 같은 출처일 때만 사용한다.
출처가 다르면 기존에 제공하는 제어 API를 확인한다.
단순 페이지 교체에는 프레임 주소를 바꿀 수 있지만, 그 결과를 실제 페이지 전환 검증으로 보고하지 않는다.

## 검수

- 데스크톱에서 왼쪽 패널과 오른쪽 전체 높이 미리보기가 참조와 같은 구조인지 확인한다.
- 페이지 선택과 후보 전환을 실행한다. 실제 내용과 선택 표시가 일치하는지 확인한다.
- 전환 목업이면 출발·이동 중·도착 상태를 확인하고 `다시 재생`으로 같은 흐름을 반복한다.
- `전체 미리보기`가 선택한 페이지나 후보를 여는지 확인한다.
- 작은 화면에서 패널 열기·선택·닫기와 키보드 초점을 확인한다. 오른쪽 페이지의 스크롤도 검사한다.
- 프로젝트 브라우저 정책에 따라 연결된 Chrome에서 확인한다. 검수 캡처와 실행할 HTML 경로나 URL을 함께 전달한다.

정적 캡처는 화면 구성의 근거다. 페이지 전환의 동작 검수는 직접 실행한 결과로 보고한다.
