## 추가된 기능

- `web-component-motion-capture`를 추가해 실제 웹 UI 조작을 MP4와 poster로 기록하고 항목별 출처·기술·시각 검증을 남깁니다.
- macOS Chrome 창 녹화 helper와 녹화 시작/종료·입력 검증용 자체 검사를 포함합니다.
- 샌드박스 실행 제한과 OS 화면 기록 권한을 구분하는 진단 절차를 제공합니다.
- 도구 포인터 배지를 피하는 키보드 촬영, 사이트 포커스 표시 보존, 탭 재연결과 raw 좌표·DPR 검증을 안내합니다.

## 설치 및 호환성

기존 7개 스킬과 검증 도구를 유지하며 새 스킬을 추가한 배포본입니다. 영상 변환은 별도 설치된 `web-video-optimize`와 ffmpeg/ffprobe를 재사용합니다. macOS 창 녹화 helper에는 ScreenCaptureKit `SCRecordingOutput`을 제공하는 macOS/Swift SDK가 필요합니다. 프로젝트별 URL·ID·크롭·출력 규격은 고정하지 않습니다.

## 검증

스킬 구조 검증, 실촬영 기반 동작 검증과 저장소 전체 테스트·패키지 재추출·SHA-256 검증을 수행했습니다. Studio375 실촬영의 영상·poster는 임시 경로에서 검증했으며 제품의 기존 에셋은 유지했습니다. 이번 릴리스의 정확한 커밋과 CI 실행은 아래 메타데이터를 참고하세요.
