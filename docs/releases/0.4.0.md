# v0.4.0

## 요청과 적용 조건

전체 페이지와 페이지 전환 목업을 같은 미리보기 틀로 판단하려는 요청에서 시작했습니다.
기준은 사용자가 제공한 페이지 전환 미리보기의 왼쪽 조작 패널과 오른쪽 전체 높이 화면입니다.
`web-ui-mockup`을 원격 배포에 처음 추가하므로 호환되는 기능 추가 버전으로 올립니다.

## 추가한 내용

- `web-ui-mockup`의 스킬 정의와 호출 메타데이터를 배포합니다.
- 전체 화면 목업 템플릿과 원본 HTML을 스킬 안에 보관합니다.
- 전체 페이지 후보는 왼쪽에서 선택하고 오른쪽에 하나씩 크게 표시합니다.
- 페이지 전환 목업은 실제 미리보기의 링크나 라우터로 이동하고 다시 재생할 수 있어야 합니다.
- 선택 상태, 전체 미리보기의 매개변수, 작은 화면 패널, 키보드 초점을 검수 기준에 포함합니다.
- 필수 등록 절차와 전달 기록 helper도 함께 배포합니다. 새 빌드 단계에서 helper의 기존 Python 검사를 실행합니다.

## 유지한 경계와 호환성

부분 UI 목업은 이미지 방식을 유지합니다. 사용자가 산출물 형식이나 레이아웃을 지정하면 그 요청을 우선합니다.
승인한 디자인을 제품에 구현하는 작업에는 목업 도구를 추가하지 않습니다.
제품 적용 승인과 패키지 등록 승인은 별개이며 스킬 설치만으로 등록하거나 hook을 설치하지 않습니다.

`harness-global v2.0.2`의 `prototype` UI 분기도 같은 참조를 사용합니다.
두 저장소의 스킬을 같은 탐색 디렉터리에 설치해야 상대 참조를 읽을 수 있습니다.
새 Python helper에는 Python 3.10 이상과 POSIX `fcntl`이 필요하며 pip 의존성은 없습니다.

보관한 HTML은 미리보기 틀의 원본입니다. 원본 페이지 콘텐츠·서버·프로젝트 전용 제어 API는 포함하지 않습니다.
목업을 만들 때 프레임 주소와 이동 연결을 작업 대상에 맞게 바꿉니다.

## 확인한 범위

- 스킬 형식, 상대 참조 경로, 호출 메타데이터와 원본 HTML의 바이트 일치를 검사했습니다.
- 독립 에이전트가 여섯 요청의 적용 분기를 검토했습니다. 이는 실제 제품 구현 검사가 아닙니다.
- 독립 에이전트가 설치한 스킬만 읽고 두 시안과 페이지 전환을 갖춘 별도 HTML 예제를 만들었습니다.
- 예제의 두 스크립트 구문과 네 시안·모션 조합에서 이동·복귀·재생·잘못된 경로·전환 단계를 검사했습니다.
- Chrome에서 전체 화면 배치, 시안 선택, 선택한 시안을 유지하는 전체 미리보기, 내부 링크의 상세 이동을 확인했습니다.
- 사용자가 예제를 직접 보고 화면을 확인했습니다.

작은 화면 패널과 다시 재생의 Chrome 검사는 완료하지 않았습니다.
예제 검사와 사용자의 화면 확인은 모든 제품이나 모든 브라우저의 동작을 보장하지 않습니다.
검증용 예제와 로컬 상태 파일은 배포하지 않습니다.
릴리스 빌드는 기존 Node 검사와 Python 검사, 압축 재해제 비교, SHA-256 검사를 실행합니다.
