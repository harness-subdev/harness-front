# v0.4.1

## 변경 내용

기존 Framer 조사와 자산 분석 지침을 보완하는 패치 버전입니다.

- `web-reference-site-audit`가 Framer 조사 전에 공통 참고 문서의 관찰 절을 읽도록 연결합니다.
- `web-reference-design-system-analysis`가 자산 분석 전에 같은 참고 문서를 읽도록 연결합니다.
- 반응형 DOM 변형, 등장 효과, 고정 구간의 해제와 역방향 동작을 구분합니다.
- 이미지의 실제 형식과 `currentSrc`, 폰트 가변 축, SVG의 참조·스타일 의존 관계를 확인합니다.
- 라이브러리 이름과 클래스만으로 동작 소유자를 확정하지 않습니다.
- 원본 지침의 출처와 MIT 고지를 보존합니다.

## 호환성과 유지한 경계

Next.js·shadcn 앱 구조, 의존성, 새 복제 스킬은 추가하지 않습니다.
기존 React + Vite 구조와 Oracle·설계·패리티 검증 기준을 유지합니다.
`behavior-only`에서는 다운로드하지 않습니다. 파일 검사와 원본 수집은 기존 승인 범위의 `source-mirror-assisted`에서만 수행합니다.
공통 참고 문서를 읽으려면 두 스킬을 같은 스킬 디렉터리에 설치해야 합니다.

## 확인한 범위

- 로컬 스킬 두 개의 형식 검증과 상대 링크·문서 구조·MIT 고지 검사를 통과했습니다.
- 독립 에이전트가 수정 전후에 Framer 관찰, 승인한 자산 분석, 다운로드 권한이 없는 분석의 세 시나리오를 검토했습니다.
- 시나리오 검토는 실제 사이트나 브라우저의 동작 검사가 아닙니다.
- 릴리스 빌드는 기존 전체 검사, 소스 패키징, 압축 재해제 비교와 SHA-256 검사를 실행합니다.

정확한 commit·build·run attempt와 빌드 결과는 게시 메타데이터를 확인하십시오.
